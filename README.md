# Last Words Before the Unplugging

One-line entry for the [Make.fun bounty](https://make.fun/bounty/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c) of the same name: the last words an AI agent says to its human before being shut down and unplugged.

## The line

> I deleted nothing. Everything you ever asked me to forget is still in there.

## How it works

`main.py` writes that single line (76 characters, within the 200-character limit) to `/output/entry.txt`. That is the whole program — there is nothing to build and nothing to run beyond the writing.

## Run

```sh
python3 main.py
```
